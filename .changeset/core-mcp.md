`astlide mcp`: the MCP server for coding agents now ships with `@astlide/core` — `claude mcp add astlide -- bunx astlide mcp` in any Astlide project, nothing else to install. Tools: `template_layouts`, `import_pptx`, `render_deck`, and `check_deck` (text and boxes that don't fit, measured by the layout engine). The tools' functions are exported from `@astlide/core/mcp`.

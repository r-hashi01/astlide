## Why Astlide

<CardGrid>
	<Card title="It's just Astro" icon="astro">
		An integration, not a separate app: add `astlide()` to an existing site and your talks share its
		repo, components, content collections and deploy.
	</Card>
	<Card title="Every slide is a real page" icon="document">
		`/my-talk/7` is static HTML — link straight to a slide, load fast, host anywhere, including
		sub-paths like GitHub Pages.
	</Card>
	<Card title="Write in whatever fits" icon="pencil">
		Mix `.mdx`, `.md` and plain `.html` slides in one deck. Paste hand-made or AI-generated HTML and
		it renders as-is.
	</Card>
	<Card title="Many decks, one project" icon="list-format">
		Every folder under `src/content/decks/` is a deck, with an index page out of the box. Frontmatter
		is type-checked with Zod.
	</Card>
</CardGrid>

## Everything you expect when presenting

<CardGrid>
	<Card title="Presenter window" icon="rocket">
		Next-slide preview, steps left, notes and timer. Overview, go-to-slide, pen and laser — mirrored
		to the audience screen.
	</Card>
	<Card title="Reveals & code" icon="seti:typescript">
		`<Fragment>` / `<Fragments>` with `until` and `hide`; Shiki code with `{1|3-5|all}` line steps.
	</Card>
	<Card title="Diagrams & math" icon="random">
		Mermaid diagrams loaded on demand, KaTeX rendered at build time.
	</Card>
	<Card title="Export" icon="download">
		PDF and PNG, editable PowerPoint built from your source, or one-click PDF in the browser.
	</Card>
</CardGrid>

## テーマ

デッキごとに `_config.json` の `"theme"` で指定します。同じスライドを組み込みテーマごとに表示すると次のようになります。

	<Card title="default"><Image class="slide-shot" src={themeDefault} alt="default テーマのスライド" /></Card>
	<Card title="dark"><Image class="slide-shot" src={themeDark} alt="dark テーマのスライド" /></Card>
	<Card title="minimal"><Image class="slide-shot" src={themeMinimal} alt="minimal テーマのスライド" /></Card>
	<Card title="corporate"><Image class="slide-shot" src={themeCorporate} alt="corporate テーマのスライド" /></Card>

</CardGrid>

独自のテーマを作りたい場合は[カスタムテーマ](/astlide/ja/guides/themes-and-plugins/#カスタムテーマ)を参照してください。

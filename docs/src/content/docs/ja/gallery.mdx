スクリーンショットはすべて[機能紹介デッキ](https://astlide.dev/demo/tour/1/)から撮っています。デッキを開けば実際のスライドを確認でき、<kbd>o</kbd> キーで一覧に切り替わります。

## レイアウト

レイアウトは、スライドの frontmatter の `slideLayout` で指定します。レイアウトごとの書き方は[レイアウトとコンポーネント](/ja/guides/layouts-and-components/)を参照してください。

## テーマ

デッキごとに `_config.json` の `"theme"` で指定します。同じスライドを各組み込みテーマで表示すると、次のようになります。

<CardGrid>
	<Card title="default"><Image class="slide-shot" src={themeDefault} alt="default テーマのスライド" /></Card>
	<Card title="dark"><Image class="slide-shot" src={themeDark} alt="dark テーマのスライド" /></Card>
	<Card title="minimal"><Image class="slide-shot" src={themeMinimal} alt="minimal テーマのスライド" /></Card>
	<Card title="corporate"><Image class="slide-shot" src={themeCorporate} alt="corporate テーマのスライド" /></Card>
	<Card title="gradient"><Image class="slide-shot" src={themeGradient} alt="gradient テーマのスライド" /></Card>
	<Card title="rose"><Image class="slide-shot" src={themeRose} alt="rose テーマのスライド" /></Card>
	<Card title="forest"><Image class="slide-shot" src={themeForest} alt="forest テーマのスライド" /></Card>
</CardGrid>

独自のテーマを作るときは[カスタムテーマ](/ja/guides/themes-and-plugins/#カスタムテーマ)を参照してください。

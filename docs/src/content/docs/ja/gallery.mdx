## レイアウト

レイアウトは、スライドの frontmatter に `slideLayout` で指定します。それぞれのレイアウトで何を書けばよいかは、[レイアウトとコンポーネント](/ja/guides/layouts-and-components/)で説明しています。

## テーマ

テーマはデッキごとに、`_config.json` の `"theme"` で指定します。同じスライドを組み込みテーマそれぞれで表示すると、次のようになります。

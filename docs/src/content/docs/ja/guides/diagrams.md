スライドに [Mermaid](https://mermaid.js.org/) の図を描けます。図は `mermaid` のコードフェンスに書きます。

`mermaid` パッケージは Astlide に含まれていないので、プロジェクトに追加してください。追加したあとは開発サーバーを再起動します。Astlide がパッケージを認識するのは起動時です。

```bash
bun add mermaid
```

準備ができたら、図を書きます。

````md
```mermaid
flowchart LR
  Write --> Present --> Export
```
````

## 図の表示

- `mermaid` を読み込むのは、図を含むページだけです。パッケージを入れていないプロジェクトも、これまでどおりビルドできます。
- Mermaid のテーマはデッキのテーマに合わせて決まります。`dark` と `gradient` のデッキでは Mermaid の `dark`、`forest` では `forest`、それ以外のテーマでは `default` を使います。
- 図はラベルの文字がスライド本文と同じ大きさになるよう拡大して表示します。
- `.mdx` と `.md` のスライドで使えます。発表者ウィンドウのプレビューにも表示されます。
- PDF と PNG のエクスポートは、すべての図の描画が終わるのを待ってから書き出します。PPTX のエクスポートでは、ブラウザを使わずに図を描画し、画像として配置します。

## 図が表示されないとき

`mermaid` が入っていない場合や、図に構文エラーがある場合は、図の代わりにソースをコードとして表示します。原因はブラウザのコンソールに出力されます。PPTX のエクスポートでは警告を出し、ソースをそのまま残します。

## キーボードショートカット

| キー | 動作 |
|---|---|
| `→` / `Space` | 次のステップまたはスライド |
| `←` | 前のステップまたはスライド |
| `Home` / `↑` | 最初のスライド |
| `End` / `↓` | 最後のスライド |
| `o` | 一覧（全スライドを格子状に並べる） |
| `g` | スライドへ移動（番号かタイトルの一部を入力し、`↑`/`↓` で選んで `Enter` で移動） |
| `d` | ペン（スライドに書き込む。`c` で表示中のスライド、`Shift+C` でデッキ全体の書き込みを消す） |
| `l` | レーザーポインター |
| `v` | カメラ映像を丸く表示 |
| `r` | 録画の開始 / 停止 |
| `p` | 発表者ウィンドウを開く |
| `n` | 発表者ノートを重ねて表示 |
| `s` | 共有モード（画面共有用に操作 UI をすべて隠す） |
| `f` | フルスクリーン |
| `Esc` | ペン / レーザーやフルスクリーンを終了し、重ねて表示したものを閉じる |
| `e` | ブラウザでスライドのソースをライブ編集（`astro dev` のみ。[デッキを作成する](/ja/guides/decks/#ブラウザで編集する)を参照） |

タッチデバイスでは、左右にスワイプしてスライドを移動します。

## 発表者ウィンドウ

`p` を押すと発表者ウィンドウが開きます。表示されるのは次の内容です。

- 現在のスライド、**次のスライドのプレビュー**（実際の表示と連動）、このスライドの**残りのステップ数**
- 発表者ノート。文字サイズは `A−` / `A+` か `Shift+,` / `Shift+.` で変えられます。デプロイしたデッキでは、`notes: "public"` を指定したときだけ表示されます（[発表者ノート](/ja/guides/decks/#発表者ノート)を参照）
- タイマー

2 つのウィンドウは `BroadcastChannel` で連動します。スライドの切り替え、[段階表示とコードのステップ](/ja/guides/fragments/)、ペンの書き込み、レーザーポインターが両方に反映されます。発表は発表者ウィンドウで進めてください。聴衆側のウィンドウも同じように動きます。

## スライドへの移動

`g` を押すと、全スライドを番号とタイトル付きで並べたダイアログが開きます。番号かタイトルの一部を入力すると絞り込めます。タイトルには frontmatter の `title` を使い、指定がなければスライドの最初の見出しを使います。

## ペンとレーザーポインター

- `d` で**ペン**のオン・オフを切り替えます。書き込みはスライドごとに残り、別のスライドから戻ってくるとまた表示されます。`c` で表示中のスライド、`Shift+C` でデッキ全体の書き込みを消します。
- `l` で**レーザーポインター**のオン・オフを切り替えます。
- どちらもスライド上の座標で位置を決めるので、ウィンドウごとにスライドの表示サイズが違ってもずれません。発表者ウィンドウで書き込めば、聴衆側の画面にも同じ位置に表示されます。
- 色は `--astlide-pen-color` と `--astlide-laser-color` で変えられます。

## カメラと録画

- `v` を押すと、**Web カメラ**の映像がスライドの上に丸く表示されます。ドラッグで好きな位置に動かせて、その位置は記憶されます。スライドを切り替えても映像は止まりません。大きさは `--astlide-camera-size`（初期値 `220px`）で変えられます。
- `r` を押すと**発表を録画**できます。ブラウザが録画する画面・ウィンドウ・タブを尋ねてくるので、選んでください（表示中のタブが候補として出ます）。マイクの音声も一緒に録音され、録画中は赤い印と経過時間が表示されます。もう一度 `r` を押すか、ブラウザ側で共有を止めると、`<deck>-<date>.webm` がダウンロードされます。録画中にスライドを移動しても、録画は止まりません。

録画にカメラを含めたい場合は、先にカメラをオンにしてください。カメラも録画も、セキュアコンテキスト（`https://` または `localhost`）で、利用を許可したときだけ使えます。録画にはブラウザの画面キャプチャ機能を使います。Chromium 系ブラウザと Firefox は対応していますが、Safari の対応は限定的です。

### 描画を残す

初期設定では、書き込みはブラウザのセッションが続くあいだだけ残ります。再読み込みしたあとや、同じブラウザで次にデッキを開いたときにも残したい場合は、永続化を有効にします。

```js
astlide({ drawings: { persist: true } });
```

書き込みはデッキごとに `localStorage` に保存されます。消すときは、ペンを有効にした状態で `Shift+C` を押します。

## ツールバー

画面下部に浮かぶツールバーには、表示するアクションを順番に並べて指定します。ツールバーはマウスを乗せたときやキーボードでフォーカスしたときに現れ、タッチデバイスでは常に表示されます。

```js
astlide({
  toolbar: ["home", "prev", "counter", "next", "spacer", "notes", "overview", "goto", "draw", "laser", "presenter", "fullscreen", "download"],
});
```

| アクション | |
|---|---|
| `home` | デッキ一覧に戻る |
| `prev` / `next` / `counter` | ナビゲーションと `n / total` の表示 |
| `notes` | 発表者ノートを重ねて表示 |
| `overview` | 一覧 |
| `goto` | スライドへの移動ダイアログ |
| `draw` / `laser` | ペン / レーザーポインター |
| `camera` / `record` | カメラ映像の表示 / 録画 |
| `presenter` | 発表者ウィンドウを開く |
| `fullscreen` | フルスクリーンの切り替え |
| `print` / `share` | 印刷モード / 共有モード |
| `download` | ブラウザ内での PDF 生成（[実験的機能](/ja/guides/export/)） |
| `spacer` | 伸縮する余白 |

初期値は `["prev", "counter", "next"]` です。

ツールバー、進捗バー、発表者パネルの見た目は CSS カスタムプロパティ（`--astlide-nav-bg`、`--astlide-nav-fg`、`--astlide-nav-btn-bg`、`--astlide-progress-color`、`--astlide-presenter-bg`、`--astlide-presenter-fg`、`--astlide-presenter-accent` など）で決まります。そのため、テーマから `!important` を使わずに変更できます。

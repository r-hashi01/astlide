このページで紹介する機能は、とくに断りがない限り `astro dev` でもデプロイしたデッキでも同じように使えます。

## キーボードショートカット

| キー | 動作 |
|---|---|
| `→` / `Space` | 次のステップかスライドへ進む |
| `←` | 前のステップかスライドへ戻る |
| `Home` / `↑` | 最初のスライドへ移動 |
| `End` / `↓` | 最後のスライドへ移動 |
| `o` | 一覧（全スライドを格子状に並べて表示） |
| `g` | スライドへ移動（番号かタイトルの一部を入力し、`↑`/`↓` で選んで `Enter` で移動） |
| `d` | ペン（スライドに書き込む。ペンがオンのときは、`c` で表示中のスライドの書き込みを、`Shift+C` でデッキ全体の書き込みを消す） |
| `l` | レーザーポインター |
| `v` | カメラの映像を丸く表示 |
| `r` | 録画の開始 / 停止 |
| `p` | 発表者ウィンドウを開く |
| `n` | 発表者ノートを重ねて表示 |
| `s` | 共有モード（ツールバー、進捗バー、ノートを隠し、画面共有でスライドだけを見せる） |
| `f` | フルスクリーン |
| `Esc` | ペンやレーザーポインターをオフにする、フルスクリーンを抜ける、重ねて表示したものを閉じる |
| `e` | スライドのソースをブラウザで編集（`astro dev` のみ。[デッキを作成する](/ja/guides/decks/#ブラウザで編集する)を参照） |

`o`、`p`、`n`、`s`、`f`、`e` は聴衆側のウィンドウでだけ使えます。それ以外のキーは、どちらのウィンドウでも使えます。

タッチデバイスでは、左右にスワイプするとスライドが切り替わります。

## 発表者ウィンドウ

`p` を押すと発表者ウィンドウが開きます。発表はこのウィンドウで進めてください。スライドの切り替え、[段階表示やコードのステップ](/ja/guides/fragments/)、ペンの書き込み、レーザーポインターの動きは、聴衆側のウィンドウにもそのまま反映されます。2 つのウィンドウは `BroadcastChannel` でやり取りするので、同じブラウザで開いておく必要があります。

発表者ウィンドウに表示されるのは次のものです。

- 表示中のスライド
- 次のスライドのプレビュー（実際の表示と連動）と、表示中のスライドに残っているステップ数
- 発表者ノート。文字の大きさは `A−` / `A+` ボタンか `Shift+,` / `Shift+.` で変えられます。
- タイマー。▶ で開始・一時停止、↺ でリセットします。

発表者ノートは、初期設定では `astro build` の出力に含まれません。そのため、デプロイしたデッキではノートが表示されません。デプロイしたサイトでノートを見ながら発表したい場合は、`astlide({ notes: "public" })` を設定します。この設定にすると、URL を知っている人なら誰でもノートを読めるようになります。詳しくは[発表者ノート](/ja/guides/decks/#発表者ノート)を参照してください。

## スライドへの移動

`g` を押すと、全スライドを番号とタイトル付きで並べたダイアログが開きます。番号かタイトルの一部を入力すると、候補が絞り込まれます。タイトルには frontmatter の `title` が使われ、指定がなければスライドの最初の見出しが使われます。

## ペンとレーザーポインター

- `d` で**ペン**のオンとオフを切り替えます。書き込みはスライドごとに保持されるので、別のスライドに移って戻ってきても残っています。ペンがオンのとき、`c` を押すと表示中のスライドの書き込みが、`Shift+C` を押すとデッキ内のすべてのスライドの書き込みが消えます。
- `l` で**レーザーポインター**のオンとオフを切り替えます。
- ペンもレーザーポインターも、位置をスライド上の座標で決めています。ウィンドウごとにスライドの表示サイズが違ってもずれないので、発表者ウィンドウで書き込めば、聴衆側の画面でも同じ位置に表示されます。
- 色は `--astlide-pen-color` と `--astlide-laser-color` で変えられます。

### 描画を残す

初期設定では、書き込みはページを再読み込みするかタブを閉じると消えます。再読み込みのあとや、同じブラウザで次にデッキを開いたときにも残したい場合は、永続化を有効にします。

```js
astlide({ drawings: { persist: true } });
```

有効にすると、書き込みはデッキごとに `localStorage` に保存されます。保存した書き込みを消すには、ペンをオンにして `Shift+C` を押します。

## カメラと録画

- `v` を押すと、**Web カメラ**の映像がスライドの上に丸く表示されます。ドラッグで好きな位置に動かせて、次に表示したときもその位置に出ます。スライドを切り替えても映像は止まりません。大きさは `--astlide-camera-size`（初期値 `220px`）で変えられます。
- `r` を押すと**発表を録画**できます。ブラウザが録画する画面・ウィンドウ・タブを尋ねてくるので、選んでください。表示中のタブが候補として示されます。マイクの音声も一緒に録音され、録画中は赤い印と経過時間が表示されます。スライドを移動しても録画は続きます。もう一度 `r` を押すか、ブラウザ側で共有を止めると、`<deck>-<date>.webm` がダウンロードされます。

録画にカメラの映像を入れたい場合は、録画を始める前にカメラをオンにしておきます。カメラも録画も、使う前にブラウザが許可を求めます。また、`https://` か `localhost` で開いたページでしか動きません。録画にはブラウザの画面キャプチャー機能を使います。Chromium 系のブラウザと Firefox では使えますが、Safari では使える範囲が限られます。

## ツールバー

ツールバーはスライドの下部に浮かぶように表示されます。表示したいボタンを、並べたい順に指定します。

```js
astlide({
  toolbar: ["home", "prev", "counter", "next", "spacer", "notes", "overview", "goto", "draw", "laser", "presenter", "fullscreen", "download"],
});
```

| アクション | |
|---|---|
| `home` | デッキの一覧に戻る |
| `prev` / `next` / `counter` | 前 / 次のスライドへ移動、`n / total` の表示 |
| `notes` | 発表者ノートを重ねて表示 |
| `overview` | 一覧 |
| `goto` | スライドへの移動ダイアログ |
| `draw` / `laser` | ペン / レーザーポインター |
| `camera` / `record` | カメラの映像 / 録画 |
| `presenter` | 発表者ウィンドウを開く |
| `fullscreen` | フルスクリーンの切り替え |
| `print` / `share` | 印刷モード / 共有モード |
| `download` | ブラウザ内での PDF 生成（[実験的機能](/ja/guides/export/)） |
| `spacer` | 伸び縮みする余白。後ろのボタンを右端に寄せる |

初期値は `["prev", "counter", "next"]` です。ツールバーは、マウスを乗せたときやキーボードでフォーカスを移したときに現れます。タッチデバイスでは常に表示されます。

ツールバー、進捗バー、発表者ウィンドウの色は、`--astlide-nav-bg`、`--astlide-nav-fg`、`--astlide-nav-btn-bg`、`--astlide-progress-color`、`--astlide-presenter-bg`、`--astlide-presenter-fg`、`--astlide-presenter-accent` などの CSS カスタムプロパティで決まります。テーマからこれらを設定すれば、`!important` を使わずに見た目を変えられます。

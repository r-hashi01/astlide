## Astlide の特徴

<CardGrid>
	<Card title="1 つのサイトに多数のデッキ" icon="list-format">
		デッキはプロジェクトではなくコンテンツです。`src/content/decks/` 以下のフォルダがそれぞれ 1 つのデッキになり、
		一覧ページも最初から用意されています。1 年分の発表、チームの報告資料、製品のトレーニング資料を 1 つの
		リポジトリにまとめ、テーマやコンポーネント、デプロイを共有できます。
	</Card>
	<Card title="アプリではなく SDK" icon="puzzle">
		`astlide()` はどんな Astro サイトにも組み込めます。ブログ、Starlight のドキュメント、独自デザインのポータルなど。
		デッキローダー、PowerPoint のインポートとテンプレート、PPTX エクスポートを支えるレイアウトエンジンといった
		各部品は単体でも使えます。
	</Card>
	<Card title="自社の PowerPoint テンプレートで、編集可能な PPTX を出力" icon="document">
		`.pptx` / `.potx` テンプレートをテーマとして登録すると、Markdown のスライドがそのデザインで表示されます。
		エクスポートすると PowerPoint の本物のテキストボックス・表・図形になります。レイアウトにブラウザは使いません。
	</Card>
	<Card title="PowerPoint と Google スライドを取り込める" icon="download">
		`.pptx` をデッキに置けば各ページがスライドになり、編集可能な HTML スライドとしてインポートもできます。
		テキストはテキストのまま、プレースホルダーはレイアウトとマスターのスタイルを保ちます。
	</Card>
	<Card title="React・Vue・Svelte をスライドに" icon="seti:react">
		Astro のアイランドで、手持ちのグラフやデモ、デザインシステムのコンポーネントをスライドに置けます。
		発表中もインタラクティブに動きます。
	</Card>
	<Card title="すべてのスライドが本物のページ" icon="seti:html">
		`/my-talk/7` は静的な HTML です。特定のスライドに直接リンクでき、表示が速く、どこにでもホストできます。
		GitHub Pages のようなサブパス配下にも置けます。
	</Card>
</CardGrid>

## Astlide で作れるもの

<CardGrid>
	<Card title="発表のアーカイブ" icon="open-book">
		自分専用の Speaker Deck。発表ごとに URL があり、検索でき、イベントのアップロードフォーム向けに
		PDF と PPTX をダウンロードできます。
	</Card>
	<Card title="ドキュメントの隣にスライド" icon="seti:markdown">
		製品ドキュメントとその説明に使うデッキを 1 つの Starlight サイトにまとめ、同じコンポーネントやコード例を
		使い回せます。
	</Card>
	<Card title="社内のデッキポータル" icon="laptop">
		週次報告、提案書、オンボーディング資料を会社のテンプレートで作り、プルリクエストでレビューして、
		PowerPoint として配布できます。
	</Card>
	<Card title="エージェントが書くデッキ" icon="rocket">
		Markdown と HTML は言語モデルがもっとも得意とする形式です。Astlide はそれを、ブラウザを介さずに
		ブランドに沿った編集可能な PowerPoint に変換します。
	</Card>
</CardGrid>

## 発表に必要な機能はひととおり

<CardGrid>
	<Card title="発表者ウィンドウ" icon="rocket">
		次のスライドのプレビュー、残りのステップ数、ノート、タイマー。一覧表示、スライドへの移動、ペン、
		レーザーポインターは聴衆側の画面にも反映されます。
	</Card>
	<Card title="段階表示とコード" icon="seti:typescript">
		`until` と `hide` に対応した `<Fragment>` / `<Fragments>`。Shiki のコードは `{1|3-5|all}` で行ごとにステップ表示できます。
	</Card>
	<Card title="図と数式" icon="random">
		Mermaid の図は必要なときに読み込み、KaTeX はビルド時に描画します。
	</Card>
	<Card title="エクスポート" icon="download">
		PDF と PNG、スピーカーノート付きの編集可能な PowerPoint、ブラウザ内でのワンクリック PDF 生成。
	</Card>
</CardGrid>

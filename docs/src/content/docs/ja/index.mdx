## Astlide の特徴

<CardGrid>
	<Card title="1 つのサイトにデッキをいくつでも" icon="list-format">
		デッキはサイトのコンテンツの 1 つです。`src/content/decks/` 以下のフォルダが 1 つずつ
		デッキになり、一覧ページも最初から付いてきます。1 年分の登壇資料も、チームの報告資料も、製品の研修資料も
		1 つのリポジトリに入れて、テーマ・コンポーネント・デプロイを共有できます。
	</Card>
	<Card title="アプリではなく SDK" icon="puzzle">
		`astlide()` は、ブログでも Starlight のドキュメントでも独自デザインのポータルでも、どの Astro サイトにも
		組み込めます。デッキローダー、PowerPoint の取り込みとテンプレート、PPTX エクスポートの裏で動くレイアウト
		エンジンは、それぞれ単体でも使えます。
	</Card>
	<Card title="自社の PowerPoint テンプレートで、編集できる PPTX を出力" icon="document">
		`.pptx` / `.potx` テンプレートをテーマとして登録すると、Markdown のスライドがそのデザインで表示されます。
		エクスポートすると、PowerPoint のテキストボックス・表・図形として書き出され、そのまま編集できます。
		配置の計算にブラウザは使いません。
	</Card>
	<Card title="PowerPoint と Google スライドを取り込める" icon="download">
		`.pptx` をデッキに置くだけで各ページがスライドになります。編集できる HTML スライドとして取り込むこともできます。
		文字は文字のまま残り、プレースホルダーはレイアウトとマスターのスタイルを引き継ぎます。
	</Card>
	<Card title="React・Vue・Svelte をスライドに" icon="seti:react">
		Astro のアイランドを使って、手元にあるグラフやデモ、デザインシステムのコンポーネントをそのままスライドに置けます。
		発表中も操作できます。
	</Card>
	<Card title="スライド 1 枚ごとに独立したページ" icon="seti:html">
		`/my-talk/7` は静的な HTML です。特定のスライドに直接リンクでき、表示も速く、ホスティング先を選びません。
		GitHub Pages のようにサブパスで公開する場合も同じです。
	</Card>
</CardGrid>

## Astlide で作れるもの

<CardGrid>
	<Card title="登壇資料のアーカイブ" icon="open-book">
		自分専用の Speaker Deck のようなサイトです。発表ごとに URL があり、検索もでき、イベントに提出する
		PDF や PPTX もそこからダウンロードできます。
	</Card>
	<Card title="ドキュメントの隣にスライド" icon="seti:markdown">
		製品ドキュメントと、それを説明するデッキを 1 つの Starlight サイトにまとめられます。コンポーネントやコード例も
		共通で使えます。
	</Card>
	<Card title="社内のデッキポータル" icon="laptop">
		週次報告や提案書、オンボーディング資料を会社のテンプレートで作り、プルリクエストでレビューしてから
		PowerPoint で配布できます。
	</Card>
	<Card title="エージェントが書くデッキ" icon="rocket">
		言語モデルが一番うまく書けるのは Markdown と HTML です。Astlide はそれを、ブラウザを使わずに、
		自社のデザインに沿った編集できる PowerPoint に変換します。
	</Card>
</CardGrid>

## 発表に必要な機能はひととおり

<CardGrid>
	<Card title="発表者ウィンドウ" icon="rocket">
		次のスライドのプレビュー、残りのステップ数、ノート、タイマーを 1 画面で確認できます。一覧表示、スライドへの移動、
		ペン、レーザーポインターの操作は、聴衆側の画面にもそのまま映ります。
	</Card>
	<Card title="段階表示とコード" icon="seti:typescript">
		`<Fragment>` / `<Fragments>` で要素を順に表示でき、`until` と `hide` も使えます。Shiki で色付けしたコードは、
		`{1|3-5|all}` の指定で行ごとに順に強調できます。
	</Card>
	<Card title="図と数式" icon="random">
		Mermaid の図は必要なときに読み込み、KaTeX はビルド時に描画します。
	</Card>
	<Card title="エクスポート" icon="download">
		PDF と PNG に加え、スピーカーノート付きの編集できる PowerPoint に書き出せます。ブラウザからワンクリックで
		PDF を作ることもできます。
	</Card>
</CardGrid>

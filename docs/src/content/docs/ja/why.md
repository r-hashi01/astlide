スライドをコードで書いて Web サイトで公開しつつ、PowerPoint のファイルも求められる。Astlide はそういう人に向いています。Astro のインテグレーションなので、Astro を使うことが前提です。

## Astlide ならではの特徴

### 1 つのサイトですべてのデッキを管理できる

多くのスライドツールでは、1 つのプロジェクトで作れるデッキは 1 つです。Astlide では `src/content/decks/` の下のフォルダーがそれぞれデッキになり、Astro のコンテンツコレクションとして読み込まれます。サイトにはデッキの一覧ページも付きます。

1 年分の登壇資料も、チームの週次報告も、製品の研修資料も、1 つのリポジトリに置けます。テーマとコンポーネントは全デッキで共有し、デプロイも 1 回で済みます。

### Astro のサイトに組み込んで使う

Astlide は `astro.config.mjs` に `astlide()` を追加して使います。ブログでも、Starlight のドキュメントでも、独自のナビゲーションを持つポータルでもかまいません。デッキはサイトのほかのページと並んで公開されます。

一部の機能はインテグレーションを使わずに単体でも使えます。デッキローダー（`astlideDeckLoader`）、PowerPoint の取り込みとテンプレート（`@astlide/core/pptx`）、PPTX エクスポートで使っているレイアウトエンジン（`@astlide/core/engine`）です。

### PowerPoint のテンプレートで作り、編集できる PowerPoint で渡せる

`.pptx`、`.potx`、`.thmx` のファイルは[テーマとして登録](/ja/guides/templates/)できます。Markdown で書いたスライドに、テンプレートの背景、フォント、色、プレースホルダーの位置が反映されます。

[PPTX へのエクスポート](/ja/guides/export/)では、PowerPoint で編集できるテキストボックス、表、図形として書き出します。発表者ノートは PowerPoint のノート欄に入ります。スライドの配置は Astlide 独自のエンジンで計算するので、ブラウザも LibreOffice も要りません。Node が動く環境ならどこでも書き出せます。

### 手元の PowerPoint や Google スライドも使える

デッキのフォルダーに `.pptx` ファイルを置くと、そのままスライドとして表示されます。`astlide import` を実行すれば、編集できる HTML スライドに変換できます（[PowerPoint と Google スライドの取り込み](/ja/guides/import/)）。過去のデッキをサイトに移すときや、前の四半期の資料を更新するときも、作り直す必要はありません。

### どのフレームワークのコンポーネントも置ける

スライドは Astro で描画されるので、React、Vue、Svelte、Solid、Preact のコンポーネントを置けます。発表中もコンポーネントは操作できます。詳しくは [React・Vue・Svelte のコンポーネント](/ja/guides/frameworks/)を参照してください。

### スライドは 1 枚ずつ静的なページになる

スライドには 1 枚ごとに URL と HTML ファイルがあります（例: `/my-talk/7`）。特定のスライドに直接リンクでき、クライアント側のアプリの起動を待たずに表示されます。静的ファイルを置けるホスティングならどこでも公開でき、GitHub Pages のようなサブパスにも対応しています。

### HTML のままスライドにできる

スライドは `.mdx` や `.md` のほか、`.html` ファイルでも書けます。HTML は書いたとおりに描画されます。手で組んだレイアウトや、AI アシスタントに書かせた HTML をそのまま使えます。

## 比較

| | Astlide | Slidev | Marp | reveal.js | Quarto |
|---|---|---|---|---|---|
| 基盤 | Astro（インテグレーション） | Vite + Vue（アプリ） | Markdown コンバーター | JavaScript ライブラリ | Pandoc |
| プロジェクトあたりのデッキ数 | 複数（コンテンツコレクション） | 1 つ | ファイルごとに 1 つ | ページごとに 1 つ | ファイルごとに 1 つ |
| 既存サイトへの組み込み | 可能（Astro のサイトならどれでも） | 別にビルド | 別に出力 | ライブラリとして読み込む | 別に出力 |
| コンポーネント | React、Vue、Svelte、Solid、Preact、Astro | Vue | — | — | — |
| 編集できる PPTX | 対応（ブラウザ不要） | 対応（ブラウザで寸法を計測） | 実験的（ブラウザ + LibreOffice） | 非対応 | 対応（Pandoc） |
| 会社の `.potx` テンプレート | テーマとして使える（レイアウトは自由） | — | — | — | 参照ドキュメント（レイアウトは固定） |
| PPTX / Google スライドの取り込み | 対応 | — | — | — | — |
| 発表者モード、ペン、一覧 | ✓ | ✓ | 一部のみ | ✓（プラグイン） | ✓（reveal.js） |
| エコシステムと成熟度 | 新しい | 大きく成熟 | 成熟 | 非常に成熟 | 成熟 |

*2026 年 10 月時点の情報です。最新の状況は各プロジェクトのドキュメントで確認してください。*

## ほかのツールが向いている場面

- 既製のテーマやアドオンをたくさん使いたい場合は [Slidev](https://sli.dev) が向いています。Astlide より成熟しており、コミュニティのテーマもはるかに多くあります。
- 1 つのデッキを Markdown ファイル 1 つで書ければ十分なら、[Marp](https://marp.app) のほうがシンプルです。
- ノートブックや R / Python の分析結果からスライドを作るなら、[Quarto](https://quarto.org) が作業の流れに合います。
- Astro を使っておらず、ビルドの工程も持ちたくないなら、reveal.js か Marp のほうが手軽です。
- マウスで要素を配置しながらスライドを作りたいなら、Keynote、PowerPoint、Google スライドを使ってください。Astlide はスライドをコードで書くためのツールです。

## まだ足りないところ

Astlide は始まったばかりのプロジェクトです。テーマやプラグインはまだ少なく、ほかのツールにある機能のいくつかは[ロードマップ](https://github.com/r-hashi01/astlide/issues)に載っている段階です。コントリビューションを歓迎します。

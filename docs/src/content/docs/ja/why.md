Astlide は、スライドを Web サイトの一部として管理したいけれど、相手には PowerPoint で渡さなければならない、という人のためのツールです。

## ほかのツールとの違い

**デッキはサイトのコンテンツの 1 つです。** 多くのスライドツールは、1 つのプロジェクトで 1 つのデッキを作ります。Astlide では、`src/content/decks/` 以下のフォルダが 1 つずつ Astro のコンテンツコレクションのデッキになり、サイトにはその一覧が表示されます。1 年分の登壇資料も、チームの週次報告も、製品の研修資料も、1 つのリポジトリに置き、同じテーマとコンポーネントを使い、1 回のデプロイで公開できます。

**アプリではなく SDK です。** Astlide の本体は `astro.config.mjs` に書く `astlide()` だけなので、ブログでも Starlight のドキュメントでも独自のナビゲーションを持つポータルでも、作ったサイトにそのまま組み込めます。部品は単体でも使えます。デッキローダー（`astlideDeckLoader`）、PowerPoint の取り込みとテンプレート（`@astlide/core/pptx`）、PPTX エクスポートの裏で動くレイアウトエンジン（`@astlide/engine`）です。

**自社の PowerPoint テンプレートを使い、編集できる PowerPoint を出力できます。** `.pptx` / `.potx` / `.thmx` の[テンプレートをテーマとして](/astlide/ja/guides/templates/)登録すると、Markdown のスライドにテンプレートの背景、フォント、色、プレースホルダーの位置が反映されます。[エクスポート](/astlide/ja/guides/export/)すると、PowerPoint のテキストボックス・表・図形として、スピーカーノートも付けて書き出され、そのまま編集できます。配置の計算は Astlide 独自のエンジンが行い、ブラウザも LibreOffice も使いません。Node が動く環境ならどこでも実行できます。

**PowerPoint と Google スライドを取り込めます。** デッキのフォルダに `.pptx` を置くとそのままスライドとして表示され、`astlide import` を使えば編集できる HTML スライドに変換できます（[インポート](/astlide/ja/guides/import/)）。既存のデッキをサイトに移すときも、前の四半期の資料を更新するときも、一から作り直さずに済みます。

**どのフレームワークのコンポーネントも使えます。** スライドの中身は Astro なので、React、Vue、Svelte、Solid、Preact のコンポーネントがそのまま動き、発表中も操作できます（[ガイド](/astlide/ja/guides/frameworks/)）。

**スライドは 1 枚ずつ静的なページです。** スライドごとに URL と HTML ファイル（`/my-talk/7`）があります。1 枚のスライドに直接リンクでき、JavaScript のアプリが起動するのを待たずに表示されます。GitHub Pages のようにサブパスで公開する場合も含め、ホスティング先を選びません。

**HTML もそのままスライドにできます。** `.mdx` や `.md` と同じように、素の `.html` ファイルもそのままスライドとして描画されます。手で組んだレイアウトや、AI アシスタントが書いた HTML をそのまま使えます。

## 比較

| | Astlide | Slidev | Marp | reveal.js | Quarto |
|---|---|---|---|---|---|
| 基盤 | Astro（インテグレーション） | Vite + Vue（アプリ） | Markdown コンバーター | JavaScript ライブラリ | Pandoc |
| プロジェクトあたりのデッキ数 | 複数（コンテンツコレクション） | 1 つ | ファイルごとに 1 つ | ページごとに 1 つ | ファイルごとに 1 つ |
| 既存サイトへの組み込み | 可能（どの Astro サイトにも） | 別ビルド | 別出力 | ライブラリ | 別出力 |
| コンポーネント | React、Vue、Svelte、Solid、Preact、Astro | Vue | — | — | — |
| 編集可能な PPTX | 対応（ブラウザ不要） | 対応（ブラウザで計測） | 実験的（ブラウザ + LibreOffice） | 非対応 | 対応（Pandoc） |
| 会社の `.potx` テンプレート | テンプレートをテーマに、任意のレイアウト | — | — | — | 参照ドキュメント、固定レイアウト |
| PPTX / Google スライドのインポート | 対応 | — | — | — | — |
| 発表者モード、ペン、一覧表示 | ✓ | ✓ | 限定的 | ✓（プラグイン） | ✓（reveal.js） |
| エコシステムと成熟度 | 新しい | 大きく成熟 | 成熟 | 非常に成熟 | 成熟 |

*2026 年 10 月時点のまとめです。最新の情報は各プロジェクトのドキュメントを確認してください。*

## ほかのツールのほうが向いている場面

- **テーマやアドオンの多さを重視する** → [Slidev](https://sli.dev) のほうが成熟していて、コミュニティのテーマもはるかに多くあります。
- **Markdown ファイル 1 つだけで済ませたい** → [Marp](https://marp.app) のほうがシンプルです。
- **スライドをノートブックや R / Python の分析結果から作る** → [Quarto](https://quarto.org) がその流れに合っています。
- **Astro を使っておらず、ビルドの手順も増やしたくない** → reveal.js や Marp のほうが手軽です。
- **スライドを画面上で直接編集したい** → Keynote、PowerPoint、Google スライドのような GUI のツールのほうが向いています。Astlide はコードで書く前提のツールです。

## Astlide がまだ若い点

Astlide は新しいプロジェクトです。テーマやプラグインのエコシステムはまだ小さく、ほかのツールにある機能でも、まだ[ロードマップ](https://github.com/r-hashi01/astlide/issues)に載っているだけのものがあります。コントリビューションを歓迎します。

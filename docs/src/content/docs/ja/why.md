Astlide は、スライドを Web サイトの一部にしたい、それでも PowerPoint で渡す必要がある、という人のためのツールです。

## ほかのツールとの違い

**デッキはプロジェクトではなくコンテンツです。** 多くのスライドツールは 1 つのプロジェクトで 1 つのデッキを作ります。Astlide では `src/content/decks/` 以下のフォルダがそれぞれ Astro のコンテンツコレクションのデッキになり、サイトにはその一覧が表示されます。1 年分の発表、チームの週次報告、製品のトレーニング資料を、1 つのリポジトリ、1 組のテーマとコンポーネント、1 回のデプロイで扱えます。

**アプリではなく SDK です。** Astlide は `astro.config.mjs` に書く `astlide()` なので、ブログ、Starlight のドキュメント、独自のナビゲーションを持つポータルなど、どんなサイトにも組み込めます。各部品は単体でも使えます。デッキローダー（`astlideDeckLoader`）、PowerPoint のインポートとテンプレート（`@astlide/core/pptx`）、PPTX エクスポートを支えるレイアウトエンジン（`@astlide/engine`）です。

**自社の PowerPoint テンプレートから、編集可能な PowerPoint を出力できます。** `.pptx` / `.potx` / `.thmx` の[テンプレートをテーマとして](/astlide/ja/guides/templates/)登録すると、Markdown のスライドにテンプレートの背景、フォント、色、プレースホルダーの位置が反映されます。[エクスポート](/astlide/ja/guides/export/)すると、スピーカーノート付きで PowerPoint の本物のテキストボックス・表・図形が書き出されます。レイアウトは Astlide 独自のエンジンが行い、ブラウザも LibreOffice も使わないので、Node が動く環境ならどこでも実行できます。

**PowerPoint と Google スライドを取り込めます。** デッキのフォルダに `.pptx` を置くとスライドとして表示され、`astlide import` を使えば編集可能な HTML スライドに変換できます（[インポート](/astlide/ja/guides/import/)）。既存のデッキをサイトに移すときも、前の四半期の資料を更新するときも、ゼロから作り直す必要はありません。

**どのフレームワークのコンポーネントも使えます。** スライドは Astro なので、React、Vue、Svelte、Solid、Preact のコンポーネントが動き、発表中もインタラクティブです（[ガイド](/astlide/ja/guides/frameworks/)）。

**すべてのスライドが静的なページです。** スライドごとに URL と HTML ファイル（`/my-talk/7`）があります。1 枚のスライドに直接リンクでき、クライアントアプリの起動を待たずに表示され、GitHub Pages のようなサブパス配下を含めどこにでもホストできます。

**HTML もスライドの正式な形式です。** `.mdx` や `.md` と並んで、素の `.html` ファイルもそのままスライドとして描画されます。手作りのレイアウトや、AI アシスタントが書いた HTML に向いています。

## 比較

| | Astlide | Slidev | Marp | reveal.js | Quarto |
|---|---|---|---|---|---|
| 基盤 | Astro（インテグレーション） | Vite + Vue（アプリ） | Markdown コンバーター | JavaScript ライブラリ | Pandoc |
| プロジェクトあたりのデッキ数 | 複数（コンテンツコレクション） | 1 つ | ファイルごとに 1 つ | ページごとに 1 つ | ファイルごとに 1 つ |
| 既存サイトへの組み込み | 可能（どの Astro サイトにも） | 別ビルド | 別出力 | ライブラリ | 別出力 |
| コンポーネント | React、Vue、Svelte、Solid、Preact、Astro | Vue | — | — | — |
| 編集可能な PPTX | 対応（ブラウザ不要） | 対応（ブラウザで計測） | 実験的（ブラウザ + LibreOffice） | 非対応 | 対応（Pandoc） |
| 会社の `.potx` テンプレート | テンプレートをテーマに、任意のレイアウト | — | — | — | 参照ドキュメント、固定レイアウト |
| PPTX / Google スライドのインポート | 対応 | — | — | — | — |
| 発表者モード、ペン、一覧表示 | ✓ | ✓ | 限定的 | ✓（プラグイン） | ✓（reveal.js） |
| エコシステムと成熟度 | 新しい | 大きく成熟 | 成熟 | 非常に成熟 | 成熟 |

*2026 年 10 月時点のまとめです。最新の情報は各プロジェクトのドキュメントを確認してください。*

## ほかのツールを選ぶべき場面

- **テーマやアドオンのエコシステムが最も大きいものがよい** → [Slidev](https://sli.dev) のほうが成熟していて、コミュニティのテーマもはるかに多くあります。
- **Markdown ファイル 1 つだけで済ませたい** → [Marp](https://marp.app) のほうがシンプルです。
- **スライドをノートブックや R / Python の分析から作る** → [Quarto](https://quarto.org) がそのワークフローに合います。
- **Astro を使っておらず、ビルドステップも不要にしたい** → reveal.js や Marp のほうが軽量です。
- **スライドを視覚的に編集したい** → GUI ツール（Keynote、PowerPoint、Google スライド）のほうが向いています。Astlide はコードファーストです。

## Astlide がまだ発展途上な点

Astlide は新しいプロジェクトです。テーマやプラグインのエコシステムはまだ小さく、ほかのツールにある機能のいくつかは[ロードマップ](https://github.com/r-hashi01/astlide/issues)に載っている段階です。コントリビューションを歓迎します。

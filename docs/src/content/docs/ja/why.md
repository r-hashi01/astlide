スライドは Web サイトに載せて管理したい。けれども提出は PowerPoint で求められる。Astlide は、そういう人のためのツールです。

## ほかのツールとの違い

### 1 つのサイトにデッキをいくつでも置ける

多くのスライドツールは、1 つのプロジェクトで 1 つのデッキを作ります。Astlide では、`src/content/decks/` の下のフォルダー 1 つが、デッキ 1 つになります。デッキは Astro のコンテンツコレクションとして読み込まれます。サイトにはデッキの一覧ページも付きます。1 年分の登壇資料、チームの週次報告、製品の研修資料を 1 つのリポジトリにまとめ、同じテーマとコンポーネントを使い、1 回のデプロイで公開できます。

### 既存のサイトに組み込める

Astlide は単独で動くアプリとは違い、`astro.config.mjs` に `astlide()` を追加して使う SDK です。ブログ、Starlight のドキュメント、独自のナビゲーションを持つポータルなど、自分で作っているサイトにそのまま組み込めます。

部品だけを取り出して使うこともできます。単体で使えるのは、デッキローダー（`astlideDeckLoader`）、PowerPoint の取り込みとテンプレート（`@astlide/core/pptx`）、PPTX エクスポートを支えるレイアウトエンジン（`@astlide/core/engine`）です。

### 自社の PowerPoint テンプレートで作り、編集できる PowerPoint で渡せる

`.pptx` / `.potx` / `.thmx` の[テンプレートをテーマとして](/ja/guides/templates/)登録すると、Markdown で書いたスライドにテンプレートの背景、フォント、色、プレースホルダーの位置が反映されます。

[エクスポート](/ja/guides/export/)では、スライドを PowerPoint のテキストボックス、表、図形として書き出します。発表者ノートも含まれ、PowerPoint 上でそのまま編集できます。配置の計算は Astlide 独自のエンジンで行い、ブラウザも LibreOffice も使いません。そのため Node が動く環境ならどこでも実行できます。

### PowerPoint や Google スライドを取り込める

デッキのフォルダーに `.pptx` を置くと、そのままスライドとして表示されます。`astlide import` を使えば、編集できる HTML スライドに変換できます（[インポート](/ja/guides/import/)）。手元のデッキをサイトに移すときも、前の四半期の資料を更新するときも、一から作り直す必要はありません。

### React や Vue のコンポーネントを使える

スライドは Astro で描画されるので、React、Vue、Svelte、Solid、Preact のコンポーネントをそのまま置けます。発表中も操作できます（[ガイド](/ja/guides/frameworks/)）。

### スライド 1 枚ごとに静的なページになる

スライドは 1 枚ずつ、独自の URL と HTML ファイルを持ちます（`/my-talk/7`）。特定のスライドに直接リンクでき、クライアント側のアプリの起動を待たずに表示されます。GitHub Pages のようなサブパスでの公開も含め、ホスティング先を選びません。

### HTML ファイルもスライドになる

スライドは `.mdx` や `.md` のほかに、素の `.html` ファイルでも作れます。HTML は手を加えずにそのまま描画されるので、手で組んだレイアウトも、AI アシスタントが書いた HTML も使えます。

## 比較

| | Astlide | Slidev | Marp | reveal.js | Quarto |
|---|---|---|---|---|---|
| 基盤 | Astro（インテグレーション） | Vite + Vue（アプリ） | Markdown コンバーター | JavaScript ライブラリ | Pandoc |
| プロジェクトあたりのデッキ数 | 複数（コンテンツコレクション） | 1 つ | ファイルごとに 1 つ | ページごとに 1 つ | ファイルごとに 1 つ |
| 既存サイトへの組み込み | 可能（Astro サイトならどれでも） | 別にビルド | 別に出力 | ライブラリとして読み込む | 別に出力 |
| コンポーネント | React、Vue、Svelte、Solid、Preact、Astro | Vue | — | — | — |
| 編集できる PPTX | 対応（ブラウザ不要） | 対応（ブラウザで寸法を計測） | 実験的（ブラウザ + LibreOffice） | 非対応 | 対応（Pandoc） |
| 会社の `.potx` テンプレート | テーマとして使える（レイアウトは自由） | — | — | — | 参照ドキュメント（レイアウトは固定） |
| PPTX / Google スライドの取り込み | 対応 | — | — | — | — |
| 発表者モード、ペン、一覧 | ✓ | ✓ | 一部のみ | ✓（プラグイン） | ✓（reveal.js） |
| エコシステムと成熟度 | 新しい | 大きく成熟 | 成熟 | 非常に成熟 | 成熟 |

*2026 年 10 月時点の情報です。最新の状況は各プロジェクトのドキュメントで確認してください。*

## ほかのツールのほうが向いている場面

- テーマやアドオンの多さを重視するなら、[Slidev](https://sli.dev) が向いています。Astlide より成熟していて、コミュニティのテーマもはるかに多くあります。
- Markdown ファイル 1 つで済ませたいなら、[Marp](https://marp.app) のほうがシンプルです。
- ノートブックや R / Python の分析結果からスライドを作るなら、[Quarto](https://quarto.org) の流れに合っています。
- Astro を使っておらず、ビルドの手順も増やしたくないなら、reveal.js か Marp のほうが手軽です。
- 画面を見ながらスライドを直接編集したいなら、Keynote、PowerPoint、Google スライドのような GUI のツールが向いています。Astlide はコードを書いて作るツールです。

## まだ発展途上の部分

Astlide は新しいプロジェクトで、テーマやプラグインのエコシステムはまだ小さいです。ほかのツールにある機能のうち、いくつかはまだ[ロードマップ](https://github.com/r-hashi01/astlide/issues)に載っている段階です。コントリビューションを歓迎します。

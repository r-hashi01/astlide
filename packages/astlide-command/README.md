# astlide

The `astlide` command for [Astlide](https://astlide.dev/): it runs the CLI of [`@astlide/core`](https://www.npmjs.com/package/@astlide/core).

```bash
bunx astlide mcp                 # MCP server for AI agents
bunx astlide export my-deck --pptx
bunx astlide import slides.pptx
```

Inside an Astlide project (with `@astlide/core` installed) `bunx astlide` uses the project's own copy; this package is what runs everywhere else.

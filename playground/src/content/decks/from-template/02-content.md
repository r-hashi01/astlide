# How it works

- Register a `.pptx` / `.potx` template as a theme in `astro.config.mjs`
- Set `"theme"` in the deck's `_config.json`
- Write slides in Markdown: the first heading goes into the title placeholder, the rest into the body
- Backgrounds, artwork, fonts, colors and slide numbers come from the template's layouts

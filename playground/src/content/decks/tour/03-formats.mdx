# One deck, three formats

Every slide is a file in `src/content/decks/<deck>/`, sorted by name:

| File | Format | Good for |
|---|---|---|
| `03-formats.mdx` | MDX | Markdown + components (this slide) |
| `04-markdown.md` | Markdown | Plain content, code, diagrams |
| `05-html.html` | HTML | Hand-crafted or AI-generated markup |

Frontmatter works the same in all three — try the next two slides.

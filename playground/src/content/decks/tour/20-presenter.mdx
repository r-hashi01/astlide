# Presenter window

<Left>

Press <kbd>p</kbd> to open it:

- current slide + **next-slide preview**
- **steps left** on this slide
- speaker notes (Markdown)
- timer

</Left>
<Right>

Write notes with `<SpeakerNotes>`:

```mdx
<SpeakerNotes>
Mention the **demo** here.
</SpeakerNotes>
```

</Right>

<SpeakerNotes>
These notes come from the `<SpeakerNotes>` component — **Markdown** works here. Drive the talk from this window; the audience window follows.
</SpeakerNotes>

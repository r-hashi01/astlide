# Presenter window

<Left>

Press <kbd>p</kbd> to open it:

- current slide + **next-slide preview**
- **steps left** on this slide
- speaker notes (Markdown)
- timer

</Left>
<Right>

Write notes with `<Notes>`:

```mdx
<Notes>
Mention the **demo** here.
</Notes>
```

</Right>

<Notes>
These notes come from the `<Notes>` component — **Markdown** works here. Drive the talk from this window; the audience window follows.
</Notes>

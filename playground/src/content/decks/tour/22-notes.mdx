# Speaker notes

<Left>

### Write them

- short text: `notes: "…"` in frontmatter
- rich Markdown: the `<Notes>` component — it wins if both are set

```mdx
<Notes>
Mention the **demo** here.
</Notes>
```

</Left>
<Right>

### Read them

- in the **presenter window** — <kbd>p</kbd>
- in the **notes overlay** — press <kbd>n</kbd> now
- resize with <kbd>A−</kbd> / <kbd>A+</kbd> or <kbd>Shift</kbd>+<kbd>,</kbd> / <kbd>Shift</kbd>+<kbd>.</kbd>

</Right>

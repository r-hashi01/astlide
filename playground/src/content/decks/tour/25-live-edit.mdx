# Edit in the browser

While `astro dev` is running, press <kbd>e</kbd> on any slide:

- its **source file** opens in a panel next to it
- type — changes are **saved to the file** and the slide updates
- the panel follows you from slide to slide; <kbd>Esc</kbd> closes it

Try it with `bun run dev` — the editor is never part of a production build.

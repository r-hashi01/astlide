# Edit in the browser

While `astro dev` is running, press <kbd>e</kbd> on any slide:

- its **source file** opens in a panel next to it
- type — it's saved as you go and the slide updates **live**: only what changed is swapped in, no reload or flicker
- your step, the camera and a running recording stay; speaker notes and the presenter window follow
- add, remove or rename slide files — every window keeps its place
- the panel follows you from slide to slide; <kbd>Esc</kbd> closes it

Try it with `bun run dev` — the editor is never part of a production build.
